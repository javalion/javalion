# Profile README

Terry's personal GitHub profile page: a place that reminds him of what he values, how he wants to act, and what he returns to.

## Language

**Profile README**:
The page GitHub displays at the top of Terry's personal profile, whose primary reader is Terry himself.
_Avoid_: Organization README, organization profile, default repo

**Value**:
Something Terry cares about, stated as a noun or short phrase. Every Value has at least one Principle.
_Avoid_: Belief, priority

**Principle**:
A rule for how Terry acts, stated as an instruction. Every Principle belongs to a Value.
_Avoid_: Rule, guideline, motto

**Meaningful Resource**:
A book, application, website, or podcast that significantly shifted how Terry thinks, in a direction he still holds. Being useful or well-liked does not qualify it.
_Avoid_: Reading list, recommendation, favorite, link
